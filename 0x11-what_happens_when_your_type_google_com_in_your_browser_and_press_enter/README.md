# What Happens When You Type google.com and Press Enter

This project explains the complete path of an HTTPS browser request, from DNS
resolution and network transport to the infrastructure and application layers
that produce the response.

## Files

- `0-blog_post` links to the public, English-language technical article.
- `article.md` covers DNS, TCP/IP, firewalls, HTTPS/TLS, load balancing, web
  servers, application servers, databases, and browser rendering.
- `1-what_happen_when_diagram` links to the public request-flow diagram.
- `request-flow.svg` illustrates the destination IP and port, encryption,
  security boundary, and server-side request path.
- `2-contribution-to_what-happens-when_github_answer` records the upstream
  project and explains why no unauthorized pull request was created.

The linked article and diagram use stable GitHub paths on the repository's
`master` branch so they become publicly available when this directory is
pushed.
